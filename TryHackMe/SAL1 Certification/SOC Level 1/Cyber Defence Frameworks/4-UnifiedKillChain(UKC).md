# Unified Kill Chain (UKC)
* Originated from military.
* Describes methodology/path attackers (hackers, APTs) use to approach and intrude a target.

## Threat Modelling
* Steps to improve the security of a system. Identifying risk and:
  * What systems/apps need to be secured.
  * Vulnerability assessment.
  * Action plan.
  * Polocing to prevent these vulnerabilities.
* STRIDE, DREAD, CVSS.
